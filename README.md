# Drum Kit

An interactive drum kit built using HTML, CSS, and JavaScript.

The project allows users to play different drum sounds by either clicking the drum buttons or pressing the corresponding keys on the keyboard.

## Features

* Play drum sounds using keyboard keys
* Play sounds by clicking the drum buttons
* Different sounds for each drum
* Interactive button effects
* Simple and responsive interface
* Audio playback using JavaScript

## Controls

| Key | Sound     |
| --- | --------- |
| W   | Tom 1     |
| A   | Tom 2     |
| S   | Tom 3     |
| D   | Tom 4     |
| J   | Snare     |
| K   | Crash     |
| L   | Kick Bass |

You can also click directly on the drum buttons to play the sounds.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* JavaScript Audio API

## How It Works

JavaScript adds click event listeners to each drum button and listens for keyboard input.

When a user clicks a button or presses one of the supported keys, the corresponding sound file is loaded and played.

## How to Run

1. Clone this repository.



2. Open the project folder.

3. Open `index.html` in your browser.

4. Click the drum buttons or use the keyboard keys to play.
